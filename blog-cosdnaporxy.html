cosDnaPorxy: 智能DNS优化工具

2024年1月 网络优化

项目简介

cosDnaPorxy 是一个基于Go语言开发的智能DNS优化工具，通过本地智能识别并篡改DNS解析结果，将Cloudflare污染或劣质IP替换为优选节点，实现无需代理的加速和防DNS污染。

核心特性

  • 本地智能识别并篡改DNS解析结果
  • 自动将Cloudflare污染或劣质IP替换为优选节点
  • 无需代理即可加速和防DNS污染
  • 高性能、低资源占用，支持多平台

快速开始

  1. 编译项目
    go build -o bin/dnsupdate main.go
# 或指定Go版本
/path/to/go build -o bin/dnsupdate main.go
  2. 运行服务
    ./bin/dnsupdate
# 或指定配置文件
./bin/dnsupdate -c configs/config.yaml

配置说明

  • 主配置文件：configs/config.yaml
  • 白名单域名：configs/whitelist.txt（可选）
  • 定向域名：configs/designated.txt

目录结构

  • internal/：核心代码（配置、DNS处理、地理数据、监控、工具）
  • configs/：配置文件
  • data/：地理位置/IP数据
  • docs/：文档
  • scripts/：证书、部署、维护脚本
  • build/：编译输出

常用命令

  • 编译：go build -o bin/dnsupdate main.go
  • 运行：./bin/dnsupdate -c configs/config.yaml
  • 测试：cd scripts/test && chmod +x *.sh && ./test_dns.sh

监控与日志

  • Prometheus指标：访问 http://localhost:9090/metrics
  • 支持不同级别日志输出，可通过配置文件调整
